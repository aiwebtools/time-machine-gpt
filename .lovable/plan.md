# Phone-first Time Travel Chat

## What will change
- Replace the dark typing field with a light, high-contrast composer so entered text is always easy to read.
- Recompose the transcript with clean assistant text, distinct high-contrast user messages, better spacing, and clearer action controls.
- Add a guided launch panel for the first step: year or era, destination, and an optional person/event. It will assemble and send the opening prompt without removing free-form chat.
- Rearrange narration, restart, microphone, image, and send controls for comfortable one-handed phone use with clear labels and borders.
- Add restrained gold portal bursts, confetti particles, depth, glow, and press feedback when a journey launches or a message sends, with reduced-motion support.
- Apply the shared redesign to all six Time Machine pages without changing their stories, personas, voices, factual rules, or existing written introductions.

## Technical details
- Compose the transcript and composer from installed AI Elements foundations while preserving the existing streaming service.
- Use semantic light-composer and celebration tokens in the global theme; avoid hardcoded component colors.
- Keep the guided launch optional after the first journey begins, and preserve microphone, narration, image generation, restart, Enter-to-send, and Shift+Enter behavior.
- Verify readability, no horizontal overflow, touch targets, send animation, and all six pages on desktop and phone.
