# Build all Time Machine branches

## Goal
Turn every existing Time Machine in the Explore menu into a dedicated on-site story experience based on the working Father Time page. Show all versions prominently on the main page as a branching set of journeys, while keeping the Explore menu as direct access to each dedicated page.

## Implementation
- Inventory the existing tool names, descriptions, artwork, and links so no version is omitted or duplicated.
- Extract the proven Father Time interface into reusable story, voice, microphone, image, and journey-continuity pieces.
- Give each Time Machine its own route, visual identity, opening prompt, narrative focus, and safe operational instructions.
- Parameterize live story and image requests with a server-approved persona identifier; never trust arbitrary client instructions.
- Replace external destinations for these Time Machines with their dedicated on-site pages in the Explore menu and footer.
- Add a clear branching section on the main page with an interactive card and launch button for every version.
- Preserve each original external destination as an optional secondary link only if the current content still needs it.
- Add all dedicated pages to the sitemap and ensure page titles and descriptions identify the selected Time Machine.

## Verification
- Test every page opening, first prompt, streamed reply, voice playback, and 16:9 image generation.
- Check the Explore menu and main-page branches on desktop and mobile.
- Confirm no duplicate tool names, broken destinations, browser errors, or missing sitemap entries.
